# 전체 화면 검증

검증일: 2026-09-26. 범위: `APP_FLOW.md`의 프론트엔드 화면 전체.

## 완료한 보완

- 키 색상을 원래 기획의 파란색으로 복원했습니다. 중복 녹색 테마를 제거하고 버튼·탭·선택·카드·그래프의 강조색을 공통 색상 변수로 연결했습니다. 버튼은 `#EAF2F9` 배경과 `#2B4A63` 글자를 사용합니다.
- 공유 대상 초안을 질문별로 보존합니다. 저장 전에는 실제 공유 범위가 바뀌지 않습니다.
- 그룹에서 질문을 바꾸면 주소가 갱신되어 새로고침과 앞뒤 이동으로 복원됩니다.
- 처음 방문한 질문 링크는 온보딩 이후에도 유지됩니다.
- 잘못된 상세 경로는 페이지 없음 화면을 표시합니다.
- 작은 화면의 온보딩을 스크롤할 수 있어 마지막 버튼까지 접근할 수 있습니다.
- 긴 그룹 이름과 소개의 가로 넘침을 방지했습니다.
- 나눔 개수는 클릭 동작이 없는 텍스트로 표시합니다.
- 이전 버전의 답변을 보존하면서 새 공유 초안 필드를 보완합니다.

## 실행 확인

```sh
npm run dev -- --host 127.0.0.1
npm test
npm run build
```

`npm test`: 상태 저장 회귀 테스트 16개 통과. `npm run build`: 성공.

연결 가능한 앱 브라우저가 없어, 새 프로필의 로컬 Chromium에서 Playwright로 검증했습니다. 사용자의 브라우저 저장 데이터는 변경하지 않았습니다.

## 화면 크기와 시각 확인

- 320×568, 390×900, 1440×900에서 주요 화면 17개씩, 총 51개 조합에 가로 넘침이 없었습니다.
- 320×480에서 시작·온보딩을 완료하고 질문 화면까지 이동했습니다.
- 그룹 이름 20자·소개 100자를 채운 320px 화면에서도 가로 넘침이 없었습니다.
- 390×844 스크린샷으로 전체 화면의 색상·간격·타이포그래피·하단 내비게이션을 확인했습니다. 긴 본문은 하단 탭 위의 영역에서 스크롤됩니다.
- 검사 중 브라우저 JavaScript 실행 오류는 없었습니다.

## 구현 경계

이 결과는 프론트엔드 데모 검증입니다. 소셜 인증, 실제 사용자·통계, 다른 기기의 그룹 초대와 전송은 서버 연동 대상입니다. 오늘은 기존 명세의 2026-09-25로 고정되어 있습니다. 실제 iOS·Android 기기의 가상 키보드와 안전 영역은 별도 기기 검증이 필요합니다.

2026-09-26 추가 검증. 자동 테스트에 아래 회귀 시나리오 7개를 추가했습니다.

- 처음 작성한 미저장 초안의 공유 제외와 변화 정도 필수 선택.

- 질문별 마지막 단계 복원과 완료한 질문의 기록 상세 연결.
- 잘못된 경로·온보딩의 진행 기록 제외와 직접 접근 잠금 유지.
- 손상된 답변 필드 복구와 정상 문장 보존.
- 손상된 그룹·멤버 복구와 정상 답변 보존.

## 선택 이유 입력 검증

2026-09-26: 선택지 아래에 선택 이유 입력란을 추가했습니다. 500자 이내의 선택 입력이며, 질문별 초안은 자동 저장되고 제출 후에는 읽기 전용입니다. 기록 상세에서 선택 당시의 이유와 이후의 성찰을 구분해 보여줍니다. 선택 이유는 개인 기록에 보존되며, 기존 그룹 공유 범위는 선택과 저장한 성찰입니다.

자동 테스트 3개를 추가해 질문별 이유 복원·성찰과 분리, 이유 없는 답변 제출, 이전 형식·손상된 이유 필드 복구를 확인했습니다. 별도 임시 Chromium에서 브라우저 확인 15개 항목을 통과했습니다. 새로고침·탭 이동 후 초안 복원, 질문별 분리, 500자 제한, 선택 필수·이유 선택 입력, 제출 후 수정 제한, 기록 상세 표시, 320px·390px의 가로 넘침과 버튼 접근을 확인했으며 실행 오류는 없었습니다. 기존 전체 화면 이미지에는 새 입력란이 반영되어 있지 않습니다.
