# 전체 화면 검증

검증일: 2026-09-26. 범위: `APP_FLOW.md`의 프론트엔드 화면 전체.

[화면 미리보기](SCREENS.jpg)

## 완료한 보완

- 키 색상을 원래 기획의 파란색으로 복원했습니다. 중복 녹색 테마를 제거하고 버튼·탭·선택·카드·그래프의 강조색을 공통 색상 변수로 연결했습니다. 버튼은 `#EAF2F9` 배경과 `#2B4A63` 글자를 사용합니다.
- 공유 대상 초안을 질문별로 보존합니다. 저장 전에는 실제 공유 범위가 바뀌지 않습니다.
- 그룹에서 질문을 바꾸면 주소가 갱신되어 새로고침과 앞뒤 이동으로 복원됩니다.
- 처음 방문한 질문 링크는 온보딩 이후에도 유지됩니다.
- 잘못된 상세 경로는 페이지 없음 화면을 표시합니다.
- 작은 화면의 온보딩을 스크롤할 수 있어 마지막 버튼까지 접근할 수 있습니다.
- 긴 그룹 이름과 소개의 가로 넘침을 방지했습니다.
- 나눔 개수는 클릭 동작이 없는 텍스트로 표시합니다.
- 이전 버전의 답변을 보존하면서 새 공유 초안 필드를 보완합니다.

## 실행 확인

```sh
npm run dev -- --host 127.0.0.1
npm test
npm run build
```

`npm test`: 상태 저장 회귀 테스트 6개 통과. `npm run build`: 성공.

연결 가능한 앱 브라우저가 없어, 새 프로필의 로컬 Chromium에서 Playwright로 검증했습니다. 사용자의 브라우저 저장 데이터는 변경하지 않았습니다.

## 화면과 동작

| 영역 | 확인 결과 |
| --- | --- |
| 시작·온보딩 | 시작, 안내 2장, 완료, 원래 질문으로 복귀 |
| 오늘·질문 모아보기 | 오늘 진입, 6개 질문, 검색 결과 없음, 필터 초기화 |
| 질문 답변 | 선택 전 제출 비활성, 질문별 초안 분리, 제출 후 선택 변경 불가 |
| 결과·의견·해설 | 직접 접근 시 미답변 잠금, 내 선택 표시, 반응, 각 질문의 해설 연결 |
| 성찰·완료 | 변화 정도 필수, 문장 자동 저장·복원, 미완료의 완료 화면 접근 제한 |
| 공유 | 미리보기, 초안 복원, 저장 전 비공개, 복수 그룹 공유, 공유 해제, 그룹 없음 |
| 그룹 | 생성, 초대 코드 참여, 잘못된 코드, 중복 가입, 멤버·초대 코드 복사 안내 |
| 그룹 나눔 | 질문 선택, 미답변 잠금, 나눔 없음, 내 게시물, 새로고침·앞뒤 이동 |
| 그룹 나가기 | 확인·취소, 해당 그룹 공유 제거, 다른 그룹 공유·개인 기록 유지 |
| 기록·상세·리포트 | 빈 상태, 6개 답변·성찰 집계, 기록 상세, 주제별 참여 개수 |
| 잘못된 경로 | 없는 화면·질문·상세 단계·탈퇴 그룹의 안내와 복귀 버튼 |

오늘 질문과 이전 질문 5개 모두 선택 → 결과 → 의견 → 해설 → 성찰 → 완료를 통과했습니다. 브라우저 검증 스크립트의 시나리오 확인 53개가 통과했습니다.

## 화면 크기와 시각 확인

- 320×568, 390×900, 1440×900에서 주요 화면 17개씩, 총 51개 조합에 가로 넘침이 없었습니다.
- 320×480에서 시작·온보딩을 완료하고 질문 화면까지 이동했습니다.
- 그룹 이름 20자·소개 100자를 채운 320px 화면에서도 가로 넘침이 없었습니다.
- 390×844 스크린샷으로 전체 화면의 색상·간격·타이포그래피·하단 내비게이션을 확인했습니다. 긴 본문은 하단 탭 위의 영역에서 스크롤됩니다.
- 검사 중 브라우저 JavaScript 실행 오류는 없었습니다.
